# hack-cc2c32ef-inspirosk

Hackathon team repository for Inspirosk

## Разбор обращений (triage)

Скрипт читает список обращений и для каждого печатает **категорию**
(`справка` / `жалоба` / `другое`) и **черновик ответа на русском**.

### Как запустить

Нужен только Python 3 (проверено на 3.9), зависимостей нет.

```bash
python3 triage.py            # разбирает messages.txt
python3 triage.py my.txt     # другой файл (одно обращение = одна строка)
python3 triage.py --json     # тот же результат в JSON
```

### Что внутри

- `messages.txt` — 5 тестовых обращений из задания, по одному в строке.
- `triage.py` — вся логика, ~150 строк:
  - **Категория** определяется правилами: для каждой категории набор регулярок
    по основам слов с весами (`пропал|не работает` → жалоба, `справк|как получить`
    → справка, `записаться|консультац` → другое). Побеждает наибольшая сумма
    весов; если ноль или ничья — `другое`. Скрипт печатает, какие именно
    признаки сработали, поэтому видно, почему принято решение.
  - **Черновик ответа** = шаблон под категорию + тематическая вставка.
    Тема (учёба / питание / ИТ / запись / парковка) определяется по тем же
    ключевым словам и даёт конкретный текст и ответственную службу, чтобы
    ответ не был пустой отпиской.

LLM не используется: на таком объёме правила отрабатывают все 5 кейсов и
не требуют ключа и сети. Если понадобится LLM — заменяется одна функция
`classify()`, остальной код не меняется.

### Что получилось

| # | Обращение | Категория |
|---|-----------|-----------|
| 1 | Как получить справку о месте учёбы? | справка |
| 2 | В столовой очередь, еда холодная. | жалоба |
| 3 | Хочу записаться на консультацию завтра. | другое |
| 4 | Пропал Wi-Fi в корпусе B. | жалоба |
| 5 | Где парковка для гостей? | справка |

Все 5 обращений разбираются корректно, каждому соответствует осмысленный
черновик ответа. Пример вывода:

```
[4] Пропал Wi-Fi в корпусе B.
    Категория: жалоба (сработало: пропал)
    Черновик ответа: Здравствуйте! Спасибо, что сообщили о проблеме, — приносим
    извинения за неудобства. ИТ-служба проверит точки доступа в указанном
    корпусе. Как временное решение — сеть guest или проводное подключение в
    читальном зале. Обращение передано в ИТ-службу; о результатах сообщим в
    течение 2 рабочих дней.
```

Ограничения: правила рассчитаны на короткие тексты и не разбирают отрицания
(«жалоб нет»); черновики — шаблонные, перед отправкой их должен просмотреть
человек.
